# Fan-free variant (initial build)

Owner decision 2026-10-21: the first mouse runs without the suction fan until test results justify it. This folder is generated by `python3 build.py --no-fan` from `../source/`. Do not edit the files here by hand.

| Path | What |
|---|---|
| `step/micromouse_revA1_nofan_assembly.step` | **Full fan-free mouse: open this in Fusion 360** (named components) |
| `step/*.step` | One STEP per part; `plate_outline.dxf` for the PCB edge cut |
| `stl/` | Printable parts. Frame, plate and battery holder differ from the fan version; hubs, bumper and sensor block are the same |
| `build_report.md` | 21 checks, mass and CG table, diagonal clearance, crash loads |
| `assets/` | Renders and drawings of this variant |

What differs from the fan version, and what to skip when building: [build guide §0](../../documentation/build_guide.md#0-build-the-fan-free-variant-first).
